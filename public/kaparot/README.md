# Kaparot page decorative assets

Drop the transparent PNGs here — the kaparot page auto-uses each one as soon as it exists
(falls back to the built-in design when a file is missing). Expected filenames:

- `rooster.png`   — hero illustration (shows the hero banner)
- `jerusalem.png` — skyline silhouette (hero backdrop + footer band)
- `pattern.png`   — subtle background texture (hero)
- `ornament.png`  — divider under the title
- `cash.png`      — step 1 icon
- `rotate.png`    — step 2 icon
- `charity.png`   — step 3 icon

Use transparent-background PNGs (no white box), ~2x resolution.
